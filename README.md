# claude-config

Shared Claude Code configuration for Linux and macOS.

New machine:

```sh
# macOS: brew install jq   ·   Linux: sudo apt install jq
git clone git@github.com:raphnah29/claude-config.git ~/claude-config
~/claude-config/install.sh
```

Then, in Claude Code: `/update-claude-config` to pull, or `/update-claude-config <change>` to change something and push.

Remote: `git@github.com:raphnah29/claude-config.git`
